# World market overview

Global Context now has a scoped navy space background with cyan/violet ambient nebula gradients and 160 deterministic SVG stars. Two star layers twinkle gently without random SSR output. The Earth bitmap makes a complete 360-degree turn around its image center every 72 seconds; this is decorative screen-space rotation, not a physically simulated axial Earth model. All new animations obey the existing pause/hidden/offscreen/reduced-motion states. Cards retain the normal readable palette above the space background. Homepage styling is unaffected.

Artwork direction: the user's first cyan digital-Earth reference best matches the blue financial UI; the third purple/magenta galaxy reference supplies complementary satellite color. Two new transparent bitmap derivatives were generated with ImageGen from the four supplied references and saved locally as `public/images/market-earth-digital-v1.png` and `public/images/market-galaxy-v1.png`. Both were visually inspected and their real alpha channels verified. They replace the flat continent/conic-gradient artwork without altering the user's original references or homepage. The Earth has restrained drift/network pulse and galaxy art spins within existing price satellites; data labels stay upright and separate. Artwork is decorative, not a map of market activity. Existing motion-pause and reduced-motion behavior remains in effect.

Latest layout separates CPI and Bloomberg world economic news into two independent carousels with synchronized clockwise orbital nodes, a 58-second orbit and opposite phases. Each feed has its own previous/next index. Small screens use separate reading lanes while the attached nodes continue orbiting. The scene grows for long cards. Four inner orbit satellites show BTC, gold futures, WTI oil futures and silver futures reference quotes, with decorative spinning galaxy icons and upright numeric labels. Values reuse existing market/commodity responses; missing/non-finite prices remain unavailable. The fixed quote ledger below the scene shows source, units, source timestamp or clearly labelled fetch time, and failed-refresh status. It stays readable even while a satellite moves behind a news panel. No additional quote-fetch requests or live-price claims are introduced. Motion follows existing hover/focus/manual/reduced-motion/visibility pauses. Tests cover quote mapping/units/timestamps/missing values, dual-panel bounds/separation and galaxy paths; total suite: 75 tests.

The news card is now a moving satellite linked to the highlighted orbital node. One animation clock projects the node, line endpoints and upright card every frame, with a 48-second orbit. Resize observers constrain the complete card within the scene on desktop/mobile. Existing hover/focus/manual/visibility/reduced-motion controls pause both the carousel and satellite movement. Two geometry tests verify finite positions, edge containment, connected endpoints and a complete revolution. Browser visual behavior remains unverified by these model tests.

The globe now has a connected one-item CPI/news carousel with source, timestamp and UTC+7. BLS items are explicitly scheduled releases, Forex Factory items show event time and supplied Actual/Forecast/Previous, and Bloomberg items show publication time. Items interleave across the available feeds every nine seconds, with previous/next and pause controls. Hover, keyboard focus, global motion pause, hidden-tab/offscreen state and reduced-motion settings stop automatic advancement. Missing feeds produce an empty/unavailable state; retained items after refresh failures are marked last loaded. Globe and detailed briefing share one fetch snapshot, so the carousel does not add duplicate feed requests. Three source-composition tests cover interleaving, time semantics, absent Actual, unsafe links, deduplication and stale labels.

The overview uses a lightweight SVG globe instead of relying on a WebGL context. Continents and orbital motion are illustrative; geography does not claim measured geographic market coverage. Pause, reduced motion, hidden-tab and offscreen behavior are supported. The statistics alongside it remain sourced from the existing CoinGecko data passed into the dashboard.

`MarketBriefing` independently fetches the existing authenticated `/api/macro` and public `/api/news` routes. It shows the next available BLS US CPI calendar event, up to three CPI events in the current Forex Factory weekly export, and up to four Bloomberg RSS headlines. Dates show Cambodia time (UTC+7). Actual is never substituted with forecast; absent values remain unavailable. Failures retain previously loaded data with a visible warning and retry. Macro is refreshed every five minutes; Bloomberg's server cache may retain its own refresh interval.

Validation: production build, lint (four existing image warnings) and all 62 tests pass. Direct public BLS/Forex Factory requests returned HTTP 200 outside the restricted network; Bloomberg endpoint returned HTTP 200. Restricted execution produced EACCES for external feeds, so the localhost-only dev server was restarted with public network access. No account/session bypass, trades, payments or private external messages were performed. Authenticated visual behavior still needs browser review.
